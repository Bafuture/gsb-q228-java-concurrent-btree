## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的有序索引要在并发写入下保持高效，节点写满时需要分裂，分裂不能阻塞全部读。请从零实现一个并发 B+ 树组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持插入、删除、按键点查与范围扫描，节点容量可配置；2) 支持节点分裂与合并，保持树的平衡（所有叶子在同一层）；3) 并发控制：读操作尽量不加全局锁，写操作只锁受影响路径，需说明加锁策略（如锁耦合）；4) 分裂期间的读一致性：分裂过程中读操作要么读到旧结构要么读到新结构，不得返回错误结果；5) 支持并发压测：多线程插入删除后树的键集合与预期一致；6) 支持有序遍历：遍历结果必须严格有序且不重不漏；7) 提供统计：树高、节点数、分裂与合并次数；8) 测试覆盖插入删除正确性、分裂合并后平衡、并发读写一致性、范围扫描、遍历完整性与统计；`mvn -q verify` 一条命令跑通。
